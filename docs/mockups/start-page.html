Start Page Mockups

Sign in, the Collections tab and the expanded Progress drawer. Grimdark (the default Theme) dark throughout, with light pairs for sign in, Option A and the drawer. 360dp frames. Sample: five Collections over two Workflows: "Standard" (Wishlist → Done, Stage colours as the starter Workflow) and "Speed paint" (Wishlist, On sprue, Built, Contrast, Done). UI only: every figure is wanted / owned / finished, models per Stage, a Workflow's name or a count of Collections or Units; percentages are computed from those.

Legend: amber note = decision, rust = problem in the current app, blue = open question or alternative.

Recommendation: Option A (frames 9–10). On the start page "how far along am I?" is the first question, so the totals belong at the top, readable without a gesture, and they scroll away instead of permanently costing ~76dp above the NavigationBar. The ProgressDrawer stays on the Collection screen, where the Units list is the point. Both show the same StageBreakdown, so the two screens still read as one system.

Proposed reusable widgets

  • ProgressRing(Progress progress, {double size = 48}): Stack of CircularProgressIndicator(value: progress.finishedShare, strokeWidth: 4, backgroundColor: surfaceContainerHighest) and the rounded % in the centre (heading font at size ≥ 64). Semantics(label: '44% finished').
  • ProgressFigures(Progress progress): Row of three equal Expanded columns, owned / finished / wanted, figure in titleLarge, word in labelMedium onSurfaceVariant, VerticalDividers between.
  • StageBreakdown(WorkflowProgress workflow): the Workflow title + totals line and banded per-Stage rows as in frame 15. Used by ProgressDrawer (expanded) and the Option A overview.
  • StageBar(progress, {double height = 4}): new optional height, as StageStrip already has; 8 in the overview, 6 on Collection and Recently painted rows.
  • RecentUnitCard(RecentUnit recent, {required VoidCallback onMove, required VoidCallback onOpen}): 164dp Card.filled + InkWell(onTap: onMove), chevron IconButton(onPressed: onOpen, tooltip: 'Open …'), footer "Move from recent.from.stage.name".
  • AuthNotice({required IconData icon, required String title, String? detail}): the sign-in error box, DecoratedBox with error border and 12% tint, Semantics(liveRegion: true).
