# Squads use Paints, by Collection and name

A paint scheme belongs to "my Intercessors", not to whichever Unit holds the models at one Stage, and Units Split and Merge constantly. So the Paints a Squad uses are recorded against its Collection and name, not against its Units as Tags and Photos are. Renaming a Squad carries its Paints along; renaming it onto an existing Squad unions the two lists, keeping the target's note for a Paint both use unless that note is empty.

## Considered Options

- **Paints on each Unit, like Tags and Photos**: fits the existing pattern, but every Split must copy the list and every Merge must reconcile two lists that may have drifted apart, while the person thinks of one scheme for the whole Squad.
- **Named, shared paint schemes linked to many Squads**: one edit updates every Squad, but adds a concept nobody needs yet; copying Paints from another Squad covers the common case.

## Consequences

A Squad whose Units are all deleted keeps its Paints, and they reappear when a Unit with that name is added to the Collection again, including through an Army List import. Deleting a Paint removes it from every Squad that uses it.
